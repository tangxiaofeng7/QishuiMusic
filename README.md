# 汽水播放器（QishuiMusic）

> **本项目仅供自我学习、技术研究使用，禁止用于任何商业用途。**

DIY 汽水音乐 iOS / Android 客户端：Flutter + Rust（FFI），单一代码库双平台
（鸿蒙适配进行中）。

## 功能

- 首页：听歌模式（45+ 场景）+ 官方推荐队列（滚动加载、播放全部、骨架屏首载）
  + **汽水FM 入口**
- **汽水FM · 无限电台**（对齐官方核心玩法）：风格电台列表（官方发现页
  电台位，带服务端主色卡）→ 一键开播 → 队列余量不足自动续歌（不重样）→
  「不喜欢」随手换下一首
- **发现页**：**排行榜**（官方榜单流）/ **歌单广场**（分页无限滚动）/
  **推荐歌单**——内容发现一页打尽
- 搜索：官方热搜词 + 搜索历史 + 联想词 + 综合搜索
  （单曲 / 歌单 / 音乐人 / 专辑，音乐人直达**艺人页**）
- **艺人页**：头像 / 收藏数 / 热门歌曲（分页）/ 专辑（直达专辑详情）/
  **关注艺人**；我的页有**我关注的艺人**列表
- **沉浸式播放页**：背景渐变与整套配色跟随**封面主色**实时取色、
  封面横滑切歌（跟手位移）、**抖音式上下滑切歌**、**封面点按切换大字歌词视图**、
  **逐字卡拉 OK 歌词**
  （扫色渐变、点击跳转、自动跟随；无逐字数据自动回退整行扫色）、
  **歌词翻译**（中英双语对照、「译」一键开关，跟随当前行高亮）、
  **相似歌曲**（官方同款入口，一曲开启无限听）、
  播放队列 / 倍速 / 睡眠定时 / **±15 秒快退快进** / 音质切换（保持进度重载）/ **一键分享**
- **播放页 DIY 美化**（个性化外观，借鉴 Beans-Music）：
  **壁纸背景**（相册导入可调模糊 / 内置渐变 / 封面取色渐变）、
  **黑胶唱片旋转封面**（方形 / 唱片两形态，播放匀速旋转、暂停停转）、
  **进度条样式**（经典 / 流光 / 辉光 / 极光 / 波浪五选一）、
  **歌词样式 DIY**（字号 / 行距 / 自定义配色 / 发光 / 3D 倾斜）、
  **主题色板**（全局主题色跟随封面取色，或 10 款预设色）、
  **快捷按钮长按拖动排序**（队列/倍速/睡眠/翻译/分享/歌词样式）
- **下一首播放**：任意曲目菜单（长按/更多）一键插队到当前曲之后，
  队列已有该曲自动挪位
- 曲目操作菜单（长按或行尾「更多」）：**收藏到歌单**（选已有 / 顺手新建）、
  喜欢、查看歌手、查看专辑、**从歌单移除**（自己歌单内）
- 歌单详情：封面头部（创建者 / 播放数 / 收藏数 / 描述）、**收藏他人歌单**、
  **重命名 / 删除**（自建歌单，改名前官方敏感词预检）、
  **排序视图**（默认 / 按歌名 / 按歌手）、
  **拖拽排序回写服务端**（自建歌单：拖动调顺序 → 全量替换提交，
  未提及条目自动垫底零丢失，跨设备生效）
- **播放页热门评论**：曲目区评论入口（总数 + 热门 5 条，头像/点赞/IP 属地/
  置顶），数据取自官方分享页链路、零签名依赖（官方评论列表端点未开放，
  只读展示）
- 专辑详情：**发行时间 / 简介 / 厂牌** 元信息 + 全曲目 + **收藏专辑**（乐观反馈）
- 我的：账号信息（VIP 标识）、**我的音乐墙**（官方个人主页对位：口味标签
  服务端配色 + 最爱曲目封面墙 + TOP 角标 + 整墙播放）、
  **我喜欢的音乐**、**抖音收藏的音乐**、
  我的歌单（分页 + **新建歌单** + **导入外部歌单**——粘贴网易云/QQ 音乐链接，
  **后台轮询导入进度，完成自动刷新**）、
  **收藏的歌单**、**收藏的专辑**、**我关注的艺人**、
  **听歌排行**（本机播放统计：最近一周 / 全部双榜，可整榜播放）、
  **最近播放**（账号同步、左滑删除单条、分页）
- 三音源取流：汽水账号 / 签名链（VIP 无损）/ 内置洛雪脚本
  （27+ 免费源：酷我 / 网易云 / 酷狗 / QQ 等，试听曲自动回落整曲）
- 设置：音质（自动/无损/极高/标准）、深浅色主题、**主题色板与个性化外观**
  （壁纸 / 唱片封面 / 进度条 / 歌词样式 / 快捷按钮排序）、
  **设置备份与恢复**（JSON 导出分享 / 剪贴板，粘贴导入）、
  **更新日志**、音源管理、缓存管理
- 体验细节：封面磁盘缓存 + 渐显、列表骨架屏、迷你条上滑进播放页、
  Material 3 深浅色全适配、品牌定制集中一处（`lib/brand.dart` 换皮）
- 后台播放 + 锁屏/控制中心控制（iOS UIBackgroundModes=audio，Android 前台服务）

## 登录（零外部依赖）

| 方式 | 条件 | 说明 |
| --- | --- | --- |
| **扫码登录（推荐）** | 手机装有官方「汽水音乐」App | 我的 → 登录 → 扫码登录。二维码用官方 App 扫一扫确认（也支持截图后「相册识别」）。`a_bogus` 网页签名由 **App 内置签名页** 提供，轮询不会被限流，**不需要任何外部服务** |
| Cookie 登录 | 从桌面版客户端 / 浏览器导出 Cookie | 粘贴包含 `sessionid_ss` / `sid_guard` 的完整会话即可 |

### 为什么没有「抖音一键登录」

官方 App 的一键登录走抖音开放平台 SDK（`douyinOpenLunaMusicV6` 通道）：
授权回跳落在**汽水注册的 Universal Link 域名**上，授权码再经
`/passport/auth/share_login/`（带应用级签名）换取会话。第三方 App
既收不到回跳授权码、也没有可用的 client_key 回跳域，**无法复刻**。
扫码登录（官方汽水 App 内即抖音账号体系）是等价的零依赖路径。

## 构建

```bash
# Rust FFI（iOS 静态库 / Android 动态库）
bash scripts/build-ios-rust.sh
bash scripts/build-android-rust.sh

# Flutter
cd app && flutter pub get
flutter build apk --release                      # Android
flutter build ipa --no-codesign --release        # iOS（bash scripts/package-ipa.sh 打包）
```

CI（`.github/workflows/build.yml`）：push 即跑 analyze / 单测门禁 + 双平台
构建；打 `v*` tag 自动发 Release 并挂安装包。
